# zombie-survivor 🧟

## ✨ Features

### 👩 Survivor Character
- Female survivor.
- Animated character movement.
- Special visual effects for shields, rapid fire and invincibility.

### 🧟 Zombie Enemies
- Multiple zombie types with unique abilities.
- Scarier zombie designs with glowing red eyes, sharp teeth and claws.
- Fast zombies, tank zombies, poison zombies and explosive zombies.
- Ranged spitter zombies.
- Powerful boss zombies with special attacks.

### 🔫 Weapons & Combat
- Four different weapons:
  - Pistol
  - Shotgun
  - Rifle
  - Laser
- Mouse-based aiming and shooting.
- Ammunition and reloading system.
- Critical hits and damage effects.

### ⚡ Special Abilities
- **Dash:** Quickly move away from enemies.
- **Energy Blast:** Damage nearby zombies.
- **Heal:** Restore health.
- **Shield:** Temporarily protect yourself from damage.

### 🏆 Progression System
- 20 challenging waves.
- Increasing difficulty as waves progress.
- XP and level-up system.
- Random perks and upgrades.
- Boss battles every fifth wave.
- Coins, rewards and high-score tracking.

### 🛒 Shop & Upgrade System
- Purchase permanent upgrades.
- Improve damage, health, regeneration, energy and speed.
- Save coins and improve your survivor.

## 🎯 Game Controls

| Key / Input | Action |
|---|---|
| W / A / S / D | Move the survivor |
| Arrow Keys | Move the survivor |
| Mouse | Aim |
| Left Mouse Button | Shoot |
| 1 / 2 / 3 / 4 | Switch weapons |
| R | Reload weapon |
| SPACE | Energy blast |
| SHIFT | Dash |
| H | Heal |
| Q | Activate shield |
| M | Toggle minimap |
| B | Open power shop |
| ESC | Pause / Resume |
